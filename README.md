# Jewellery Shop Management System

## Description
A DBMS mini project developed using PHP, MySQL, HTML, CSS, and JavaScript.

This system manages:

- Customers
- Orders
- Goldsmiths
- Payments
- Deliveries

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP

## Features
- Add customer records
- Manage goldsmith details
- Track jewellery orders
- Store payment information
- Delivery status management
- Database connectivity using MySQL
- View records in tabular format

## Database Concepts Used
- Primary Key
- Foreign Key
- INSERT Query
- SELECT Query
- Relational Database
- CRUD Operations
